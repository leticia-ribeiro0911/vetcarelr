# Product Backlog — VetCare LR

**Nome do projeto:** VetCare LR

**Objetivo:** Desenvolver um sistema para facilitar a organização de um hospital veterinário.

## 1. Lista de funcionalidades

| ID | Funcionalidade | Descrição | Prioridade |
|---|---|---|---|
| PB01 | Página inicial | Apresentar as principais informações do hospital veterinário. | Alta |
| PB02 | Serviços | Mostrar os serviços oferecidos pelo hospital, como consultas, vacinas, exames e cirurgias. | Alta |
| PB03 | Cadastro de tutores | Permitir que os tutores se cadastrem com nome, CPF, telefone e senha. | Alta |
| PB04 | Login de tutores | Permitir que os tutores entrem no sistema usando CPF e senha. | Alta |
| PB05 | Sair da conta | Permitir que o usuário encerre sua sessão com segurança. | Média |
| PB06 | Cadastro de animais | Permitir o cadastro dos animais, informando nome e tipo de animal. | Alta |
| PB07 | Solicitação de agendamentos | Permitir que os tutores solicitem atendimentos para seus animais. | Alta |
| PB08 | Informações do agendamento | Permitir que o tutor informe o tipo de atendimento, a data desejada e outras observações. | Alta |
| PB09 | Visualização dos agendamentos | Permitir que os funcionários visualizem os agendamentos solicitados. | Alta |
| PB10 | Confirmação dos agendamentos | Permitir que os funcionários entrem em contato com os tutores pelo WhatsApp para confirmar os atendimentos. | Alta |
| PB11 | Status dos agendamentos | Permitir que os funcionários atualizem o status dos atendimentos para ativo, em andamento ou concluído. | Alta |
| PB12 | Login dos funcionários | Permitir o acesso dos funcionários à área administrativa do sistema. | Alta |
| PB13 | Lista de tutores e animais | Permitir que os funcionários consultem os dados dos tutores e dos animais cadastrados. | Alta |
| PB14 | Configurações | Permitir a atualização do horário de atendimento, endereço, telefone e e-mail do hospital. | Média |
| PB15 | Verificação dos dados | Verificar se os campos obrigatórios foram preenchidos corretamente. | Alta |
| PB16 | Navegação do site | Organizar os menus e links para facilitar a navegação entre as páginas. | Alta |
| PB17 | Sobre e contato | Apresentar informações sobre o hospital e seus meios de contato. | Média |

## 2. Funcionamento das funcionalidades

- **Página inicial:** deve apresentar o VetCare LR e facilitar o acesso às outras páginas.
- **Serviços:** deve mostrar os atendimentos oferecidos pelo hospital.
- **Cadastro e login:** os tutores devem conseguir criar uma conta e entrar no sistema.
- **Cadastro de animais:** cada animal deve ficar vinculado ao seu tutor.
- **Agendamentos:** o tutor deve conseguir solicitar um atendimento, informando os dados necessários.
- **Área dos funcionários:** os funcionários devem conseguir visualizar os agendamentos e consultar os dados cadastrados.
- **Confirmação dos atendimentos:** os funcionários devem entrar em contato com os tutores para confirmar os agendamentos.
- **Status:** os funcionários devem conseguir atualizar a situação dos atendimentos.
- **Configurações:** as informações do hospital devem poder ser atualizadas quando necessário.


## 3. Observações

- O VetCare LR será voltado para o atendimento de diferentes tipos de animais, incluindo cães, gatos, bovinos e equinos.

- A página de serviços poderá apresentar os atendimentos disponíveis sem precisar de uma tabela própria no banco de dados por enquanto.
