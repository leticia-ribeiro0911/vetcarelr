## Objetivo
Criar um sistema web para um hospital veterinário, permitindo o gerenciamento de tutores, animais, veterinários, consultas, prontuários, exames, vacinas e outros atendimentos.

### Área Pública:
- Apresentação do hospital
- Serviços
- Equipe
- Estrutura
- Informações de contato
- Agendamento

### Área Administrativa:
- Login
- Cadastros
- Edição
- Exclusão
- Consultas
- Prontuários
- Controle dos atendimentos

### O sistema será utilizado internamente por:

- Veterinários
- Recepcionistas
- Administradores
- Funcionários do hospital
